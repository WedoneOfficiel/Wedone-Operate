# Réouverture du canal bêta : bienvenue dans le Projet Phoenix

**Wedone Operate — Beta 2026.11.02**  
**2 novembre 2026 — WedoneOfficiel**

Après une période sans canal bêta, celui-ci rouvre avec le **Projet Phoenix**, une reconstruction majeure de Wedone Operate.

L'objectif n'est pas de publier une simple mise à jour de l'ancienne application : Phoenix repart sur une base technique neuve, une interface entièrement repensée et une gestion des données plus sûre.

## Ce qui arrive dans cette première bêta

- **Nouvelle application** : architecture PySide6 et Qt Quick / QML, avec une interface reconstruite.
- **Deux modes d'utilisation** : espace individuel avec accès direct à la pratique, ou usage en classe avec accès distincts pour les élèves et les professeurs.
- **Calcul mental** : premiers générateurs pour les additions, soustractions, multiplications, divisions exactes et nombres relatifs ; difficultés réglables et prévention des doublons.
- **Séances enregistrées** : réponses, corrections, temps de réponse et résultats conservés, y compris lorsqu'une séance est abandonnée.
- **Espace classe initial** : profils professeurs protégés, classes, groupes, élèves, sélection de profils et archivage avec conservation de l'historique.
- **Premières statistiques** : séances, réponses, taux de réussite et progression par compétence.
- **Données protégées** : nouvelle base SQLite, sauvegardes, restauration avec copie de sécurité, export/import JSON et réinitialisation confirmée.
- **Accessibilité** : échelle de l'interface, contraste renforcé et réduction des animations.
- **Trois plateformes** : chaîne de compilation dédiée à Windows x64, macOS Apple Silicon et Linux x64.

## Une bêta, pas une version stable

Cette première livraison ouvre le chantier et ne prétend pas couvrir dès aujourd'hui toutes les compétences du CP à la Terminale. Seuls les exercices dont le générateur est implémenté et testé sont activés. Les statistiques, la gestion de classe, les parcours et l'interface vont continuer à évoluer.

Les retours sont donc particulièrement importants : problèmes au démarrage, affichage, exercices, sauvegardes, navigation ou compatibilité avec votre système.

Le canal bêta est officiellement rouvert pour accompagner cette reconstruction. **Phoenix Beta 2026.11.02 n'est pas une version stable et ne doit pas être considérée comme une livraison de production.**

Merci à toutes celles et ceux qui participeront aux essais !
